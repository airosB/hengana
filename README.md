# 変体仮名フラッシュカード

変体仮名を覚えるためのブラウザ用フラッシュカードアプリ。
画像は[変体仮名 五十音順一覧](http://www.book-seishindo.jp/kana/onjun_1.html)より取得。

## 使い方

`index.html` をブラウザで直接開く。サーバー不要。

## モード

- **変体仮名を読む** — 変体仮名の画像を見て字母（漢字+読み）を答える
- **漢字から読みを当てる** — 字母の漢字を見て読みを答える

## レベル

| レベル | 内容 |
|--------|------|
| 1 | 比較的よく使われる変体仮名（260枚）|
| 2 | 現行の五十音かなと同じ字母（198枚）|
| 3 | その他（275枚）|

## 画像の再取得

```
python3 fetch_data.py
```

`images/` と `data.js` が再生成される。
